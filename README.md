# KdV Equation

Repository containing materials, exercises, and implementations developed for a tutoring session on numerical methods for partial differential equations, with a focus on the **Korteweg–de Vries (KdV) equation**.

## Topics

The repository covers:

- **Finite Element Methods**
- **Finite Difference Methods**
- Numerical solution of partial differential equations
- Numerical approaches to the **KdV equation**

## Contents

The repository includes:

- Jupyter notebooks with implementations and examples
- Python scripts for numerical methods
- Reference papers and academic materials
- Exercises and supporting material from the tutoring sessions

## Academic Context

This repository was developed as part of a **tutoring/teaching assistantship (monitoría)** in an undergraduate **Mathematical Engineering** program.

The material focuses on numerical methods for solving partial differential equations, particularly finite element and finite difference approaches.

## Tools

`Python` · `Jupyter Notebook` · `Finite Element Method` · `Finite Difference Method`
